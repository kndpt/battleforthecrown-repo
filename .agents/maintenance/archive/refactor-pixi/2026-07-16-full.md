# refactor-pixi — 2026-07-16 — locale-number-format

## Theme

LOCALE-01: consolidate 24 inline `.toLocaleString()` calls across 12 production
files into the shared `NUMBER_FMT.format()` singleton from `lib/formatters.ts`.

### Problem

24 production call sites used `.toLocaleString()` for fr-FR number formatting
instead of the shared `NUMBER_FMT` singleton. ~10 of these calls omitted the
locale argument entirely (`.toLocaleString()` with no args), which would fall
back to the user's browser locale — inconsistent formatting for non-fr-FR
browsers. All sites now use `NUMBER_FMT.format()`, guaranteeing fr-FR locale.

### Locale bug fixed

10 call sites used `.toLocaleString()` without specifying `'fr-FR'`:
- AttackDetailModal.tsx:494,499
- CostSection.tsx:36,39,48
- BonusSection.tsx:120
- PowerBadge.tsx:23
- UnitCard.tsx:353

These would display browser-default locale formatting (e.g., `1,234` in en-US
instead of `1 234` in fr-FR). Now consistent across all browsers.
