## Looks bad but fine

- `frInt` / `frShort` in `villageMapPanel/meta.ts` — design-system preview only, consumed by the village map panel; `frShort` has K/M abbreviation logic that differs from resourceConfig formatters. Intentionally separate.
- `formatNumber` in `PowerBottomSheet.tsx:15` — includes `Math.max(0, Math.floor(value))` clamping, used for power display. Semantically different from a plain locale formatter.
- Inline `.toLocaleString('fr-FR')` in `NumericKeypad.tsx`, `multiVillageSheet.ts`, `profileViewModel.ts`, `DailyQuestModal.tsx`, `MultiVillageBottomSheet.tsx` — context-specific one-offs in JSX/template strings where extracting a function would be less readable.

## Fixes applied

### NEW-02 — NUMBER_FORMATTER alias elimination
Removed `const NUMBER_FORMATTER = NUMBER_FMT;` from 8 files, replaced all `NUMBER_FORMATTER` usages with `NUMBER_FMT`:
- `caravanReportView.ts`
- `ReportDetailModal.tsx`
- `scoutReportView.ts`
- `reinforcementReportView.ts`
- `ReportCard.tsx`
- `TroopBar.tsx`
- `ReportsList.tsx`
- `PublicPlayerProfileSheet.tsx`

Also merged split imports in `ReportsList.tsx` (two separate `@/lib/formatters` imports → one).

### NEW-03 + FMT-01..05 — Private formatter consolidation
Added `formatIntFr(n)` to `lib/formatters.ts` for the `Math.floor + locale` pattern.

- `SpecializedBuildingDetailModal.tsx`: `fr()` → `formatIntFr()` (3 call sites)
- `ResourceBuildingModal.tsx`: `fr()` → `formatIntFr()` (8 call sites)
- `TroopDetailModal.tsx`: `formatCount()` → `NUMBER_FMT.format()` (4 call sites)
- `ArmyViewDesign.tsx`: `formatNumber()` → `NUMBER_FMT.format()` (10 call sites)
- `armyViewModel.ts`: `formatPowerSummary()` → `NUMBER_FMT.format()` (2 call sites)
- `rankingsFormat.ts`: `formatScore()` now delegates to `NUMBER_FMT.format()` (kept export for 3 importers)
- `caravanReportView.ts`: `formatResource()` → `NUMBER_FMT.format()` (12 call sites)
