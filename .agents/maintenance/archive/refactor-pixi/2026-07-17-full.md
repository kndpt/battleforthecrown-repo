## Changes applied

### D-NEW-01: Duration formatters → shared `formatDuration`

Added `formatDuration(ms, opts?)` to `lib/formatters.ts`:
- Default: `h:mm` or `m:ss` (compact mode, drops seconds when hours present)
- `{ showFullSeconds: true }`: `h:mm:ss` or `m:ss` (travel time mode)

Replaced 4 private/local formatters:
- `formatTravelTime` in `lib/combatHelpers.ts` → delegates to `formatDuration(ms, { showFullSeconds: true })`
- `formatQueueTime` in `VillageViewSectionHelpers.ts` → delegates to `formatDuration(ms)`
- `formatCompactRemaining` in `multiVillageSheet.ts` → `ms <= 0 ? '—' : formatDuration(ms)`
- `formatProgressTime` in `UnitCard.tsx` → removed, replaced by `formatDuration` import

7 test cases added in `lib/formatters.test.ts`. Existing tests (combatHelpers.test.ts, VillageViewSections.test.ts) pass unchanged.

### D-NEW-08: Strategy labels → shared `STRATEGY_LABELS`

Created `lib/strategyLabels.ts` deriving from `villageStyleOptions` (design-system canonical source).

Replaced 3 independent maps:
- `STYLE_LABELS` in `intelView.ts` → import `STRATEGY_LABELS`
- `strategyLabels` in `profileViewModel.ts` → re-export from `STRATEGY_LABELS`
- `scoutReportStrategyLabel` in `scoutReportView.ts` → uses `STRATEGY_LABELS` instead of `DEFAULT_VILLAGE_STRATEGY.strategies[...].displayName`, also removes `VillageStrategyType` import and `as VillageStrategyType` cast (TYPE-03 closed)

### WS-23: Missing incomingAttacks invalidation

Added `queryKeys.incomingAttacks(payload.defenderVillageId)` invalidation to `applyVillageAttacked` in `ws-bindings.ts`. After a battle resolves for the defender, the incoming-attack threat card now clears immediately instead of persisting for up to 5s (stale refetchInterval).

Test added in `ws-bindings.test.ts`.
