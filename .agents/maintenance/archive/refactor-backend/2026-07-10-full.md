## Thème retenu

**Single-home resource-affordability guard** → `shared/resources.hasSufficientResources`.

Le guard "insufficient resources" était inliné en comparaison 3-ressources (`stock.wood < cost.wood || stock.stone < cost.stone || stock.iron < cost.iron`) dans 4 flux backend. Consolidé dans un helper pur shared, à côté de `creditResourcesCapped`.

### Helper

`packages/shared/src/resources/storage.ts`
```ts
export const hasSufficientResources = (
  current: ResourceAmounts,
  cost: ResourceAmounts,
): boolean =>
  current.wood >= cost.wood &&
  current.stone >= cost.stone &&
  current.iron >= cost.iron;
```
Behavior-preserving : `!hasSufficientResources(stock, cost)` ≡ ancien `wood < || stone < || iron <` (De Morgan). Population + crowns restent gérés séparément par chaque callsite.
