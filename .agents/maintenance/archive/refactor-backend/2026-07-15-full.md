# refactor-backend — 2026-07-15 — DUP-REPORT

## Thème

Fusion du CRUD inbox dupliqué entre `caravan-report.service.ts` et
`reinforcement-report.service.ts` (~80% identique) dans une base abstraite
partagée `InboxReportService<TReport, TResponse>`.

## Constat (Phase 1 — backlog `.state.md`)

DUP-REPORT (Med, candidat #1). Les deux services :

- Même type payload `Prisma.InboxEntryGetPayload<{ include: { <report>: true } }>`.
- Même orchestration `getAll` (ownership → findMany kind+hidden:false → filter+map présenter).
- Même `get`/`markRead`/`delete` (ownership → findEntry → update/present).
- Même `findEntry` (findFirst kind+FK+hidden).

Divergence réelle **préservée** :
- caravan `findCaravanEntry` hardcode `hidden:false` → mark/delete **404** sur une entrée hidden.
- reinforcement gate `excludeHidden` par op → read exclut hidden, mark/delete **idempotents** sur hidden.

## Changement

Nouveau `combat/inbox-report.service.ts` — `abstract class InboxReportService<TReport, TResponse>` :

- Membres abstraits : `kind: InboxKind`, `include: Prisma.InboxEntryInclude`,
  `notFoundMessage`, `mutationExcludesHidden: boolean`, `reportIdFilter()`,
  `extractReport()`, `present()`.
- Méthodes protégées : `listReports`, `readReport` (toujours `excludeHidden:true`),
  `markReportAsRead` / `deleteReport` (gated par `mutationExcludesHidden`), `findEntry` (privé).
- Sémantique hidden-gating documentée **une seule fois** dans le JSDoc de la classe.

Concrets réécrits (extends la base) :
- `CaravanReportService` : `kind='CARAVAN'`, `mutationExcludesHidden=true`.
- `ReinforcementReportService` : `kind='REINFORCEMENT'`, `mutationExcludesHidden=false`.
- Noms de méthodes publiques (`getAllCaravanReports`, etc.) **conservés** via wrappers 1-ligne
  → controller + presenter specs + smokes inchangés.

Type-debt : un seul cast contrôlé par concret (`entry as <Entry>WithReport`) dans
`extractReport`, isolé et commenté — **identique** au cast qui existait déjà dans chaque
`findEntry` (net : 2 casts → 2 casts, mais centralisation de la logique). Pas d'`any`.

Diff : `+100 / −140` sur les 2 services + nouveau fichier base (~145L). Net LOC ≈ neutre,
gain = source unique pour la sémantique hidden-gating subtile.
