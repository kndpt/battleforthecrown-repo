## Note découverte pendant l'audit

`generateBarbarianName` : le suffixe est indexé via `(seed + tier.charCodeAt(0)) % suffixes.length` — or tous les tiers commencent par `"T"`, donc `charCodeAt(0)` est identique pour T1..T5. Le tier n'influence en pratique jamais le nom généré, seules les coordonnées le font. Pas un bug (le nom reste déterministe et unique par position), juste documenté — un futur refactor de nommage par tier devrait utiliser autre chose que le premier caractère.
